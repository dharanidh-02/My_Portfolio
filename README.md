# Premium AI Engineer Portfolio - Dharanidharan T

An ultra-modern, cinematic portfolio built with React, Vite, Tailwind CSS v4, and Spline 3D.

## ✨ Features
- **Futuristic 3D Experiences**: Interactive Spline robot and immersive 3D background sections.
- **Buttery Smooth Scroll**: Integrated Lenis for a premium browsing experience.
- **Dynamic Animations**: Powered by Framer Motion and GSAP for scroll-triggered and hover effects.
- **Glassmorphism UI**: High-end sleek design inspired by Linear, Apple, and Vercel.
- **SEO Optimized**: Fully responsive with proper meta tags and accessibility.

## 🛠️ Tech Stack
- **Framework**: React.js 19 + Vite 6
- **Styling**: Tailwind CSS v4 (CSS-first configuration)
- **Animations**: Framer Motion, GSAP
- **3D**: Spline (@splinetool/viewer)
- **Icons**: React Icons, Lucide React
- **Scrolling**: Lenis

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation
1. Clone the repository or navigate to the project folder.
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the development server:
```bash
npm run dev
```

### Production Build
Build for production:
```bash
npm run build
```
The output will be in the `dist/` directory.

## 📁 Project Structure
- `src/sections/`: Individual page sections (Hero, About, Projects, etc.)
- `src/components/`: Reusable global components (Navbar, Cursor, Loader)
- `src/index.css`: Tailwind v4 theme and global styles
